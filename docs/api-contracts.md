# API Contracts

The **OpenAPI 3.1 schema generated by drf-spectacular is the source of truth.** This document covers conventions and the planned endpoint map. Endpoint details live in the schema:

- Schema: `GET /api/v1/schema/`. Swagger UI: `/api/v1/docs/`. ReDoc: `/api/v1/redoc/` (non-production, or staff-only in production).
- Frontend types: `npm run api:types` → `frontend/src/lib/api/schema.d.ts` (`openapi-typescript`). The client is `openapi-fetch`.
- CI: regenerate the schema and types, and fail if `git diff` is non-empty. Any **breaking** change (removed field, changed type, removed endpoint) requires an entry in the [Changelog](#changelog) and a version bump or a deprecation period.

## Conventions

| Topic | Convention |
|---|---|
| Base path | `/api/v1/` (same origin as the storefront via Caddy) |
| Format | JSON, `snake_case` fields |
| Auth | Django session cookie. `GET /api/v1/auth/csrf/` primes the CSRF cookie, and unsafe methods send `X-CSRFToken`. |
| Money | `{ "amount": 1249900, "currency": "INR", "formatted": "₹12,499" }`. `amount` is in **paise** (integer). The client never does money arithmetic for charging. |
| IDs | UUID strings. Orders, returns and invoices also expose `number`. |
| Timestamps | ISO 8601 UTC (`2026-11-17T08:51:00Z`). The UI renders in `Asia/Kolkata`. |
| Pagination | Catalogue: page-number (`?page=2&page_size=24`) → `{count, next, previous, results}`. Admin lists and feeds: cursor (`?cursor=`). |
| Filtering | Query params, multi-value comma-separated: `?category=sherwanis&occasion=wedding,reception&colour=ivory&size=40&price_min=2000000&price_max=8000000&fit=slim&fulfilment=made_to_measure&in_stock=true` |
| Sorting | `?ordering=` one of `featured`, `newest`, `price_asc`, `price_desc`, `bestselling` |
| Idempotency | `Idempotency-Key` header **required** on `POST /checkout/{id}/place-order/`, `POST /payments/razorpay/verify/`, and staff refund/cancel. Same key + same body → same response. Same key + different body → `409`. Stored 24h. |
| Rate limits | `429` with `Retry-After` |
| Request id | `X-Request-ID` echoed on every response and included in errors |

### Error envelope
```json
{
  "error": {
    "code": "out_of_stock",
    "message": "Only 1 left in size 40.",
    "details": { "variant_id": "0193…", "available": 1 },
    "fields": { "quantity": ["Ensure this value is less than or equal to 1."] },
    "request_id": "c0a8…"
  }
}
```
Stable `code` values (the frontend switches on these): `validation_error`, `not_authenticated`, `permission_denied`, `not_found`, `conflict`, `rate_limited`, `out_of_stock`, `price_changed`, `quote_expired`, `coupon_invalid`, `coupon_not_applicable`, `pincode_not_serviceable`, `cod_unavailable`, `payment_verification_failed`, `payment_amount_mismatch`, `order_not_cancellable`, `return_not_eligible`, `refund_exceeds_captured`, `idempotency_conflict`.

## Endpoint map (v1)

### Auth & account (`accounts`, `customers`)
| Method | Path | Notes |
|---|---|---|
| GET | `/auth/csrf/` | Sets CSRF cookie |
| POST | `/auth/register/` | `{email, password, first_name, last_name, phone?, marketing_opt_in}` |
| POST | `/auth/login/` · `/auth/logout/` | Rotates the session. Merges the guest cart. |
| GET | `/auth/me/` | `{id, email, first_name, is_staff, roles[], permissions[]}` |
| POST | `/auth/password/reset/` · `/auth/password/reset/confirm/` · `/auth/email/verify/` | |
| GET/PATCH | `/account/profile/` | |
| CRUD | `/account/addresses/` | `POST /{id}/set-default/` |
| CRUD | `/account/measurements/` | Body measurement profiles (MTM) |

### Catalogue (`catalog`, `categories`, `attributes`)
| Method | Path | Notes |
|---|---|---|
| GET | `/catalog/categories/` | Tree |
| GET | `/catalog/categories/{path}/` | Editorial header + SEO |
| GET | `/catalog/collections/` · `/catalog/collections/{slug}/` | |
| GET | `/catalog/products/` | Listing with filters/sort. Each item: `{id, slug, name, category, price{mrp, sale, from}, badges[], primary_image, hover_image, colours[{name,hex,slug,image}], is_mtm_available, in_stock}` |
| GET | `/catalog/products/facets/` | Same filters → facet counts `{colour:[{slug,name,hex,count}], size:[…], price:{min,max}, …}` |
| GET | `/catalog/products/{slug}/` | Full PDP: attributes, media grouped by colour, variants `[{id, sku, colour, size, price, stock_status: in_stock/low_stock/out_of_stock/made_to_order, low_stock_qty?}]`, size chart, measurement definitions, care, specifications, rating summary, SEO |
| GET | `/catalog/products/{slug}/related/` · `/complete-the-look/` | |
| GET | `/catalog/search/suggest/?q=` | `{products[≤6], categories[≤4], queries[≤5]}`, trigram-ranked, ≤ 80ms p95 target |
| GET | `/catalog/search/?q=` | Same shape as the listing, with relevance ordering |
| GET | `/catalog/size-charts/{id}/` · `/catalog/measurement-guide/` | Garment chart vs body guidance, kept separate |

### Cart, wishlist, checkout
| Method | Path | Notes |
|---|---|---|
| GET | `/cart/` | Server-computed lines, totals and messages (`price_changed`, `low_stock`) |
| POST | `/cart/lines/` | `{variant_id, quantity, measurement_profile_id?}`. **No price accepted.** |
| PATCH/DELETE | `/cart/lines/{id}/` | |
| POST/DELETE | `/cart/coupon/` | `{code}` |
| GET/POST/DELETE | `/wishlist/items/` | |
| GET | `/shipping/pincode/{pincode}/` | `{serviceable, cod_available, eta:{min_days,max_days}, city, state}` |
| POST | `/checkout/` | Creates a `CheckoutSession` from the cart, or returns the open one |
| PATCH | `/checkout/{id}/` | `{email, phone, shipping_address \| address_id, billing_same, shipping_method, payment_method}` → returns the recomputed `quote` |
| GET | `/checkout/{id}/quote/` | `{lines[], subtotal, discount, shipping, cod_fee, tax{cgst,sgst,igst,total}, total, quote_hash, expires_at}` |
| POST | `/checkout/{id}/place-order/` | **Idempotency-Key.** Body `{quote_hash}`. A mismatch returns `409 price_changed` with the new quote. Responses: Razorpay → `{order, payment:{provider:"razorpay", key_id, razorpay_order_id, amount, currency, prefill}}`. COD → `{order}` (status `confirmed` or `pending_otp`). |

### Payments
| Method | Path | Notes |
|---|---|---|
| POST | `/payments/razorpay/verify/` | `{razorpay_order_id, razorpay_payment_id, razorpay_signature}` → server HMAC-SHA256 check with the key secret, plus an amount/status check via the Razorpay API. Idempotent. |
| POST | `/payments/razorpay/webhook/` | No session or CSRF. Verifies `X-Razorpay-Signature` against the **webhook secret** over the raw body. Deduped on `x-razorpay-event-id`. Always returns `200` for valid signatures (even duplicates) and `400` for invalid ones. Events: `payment.captured`, `payment.failed`, `order.paid`, `refund.processed`, `refund.failed`. |
| POST | `/payments/{order_number}/retry/` | New Razorpay order for `payment_failed` orders still within the window |
| POST | `/orders/{number}/cod/verify-otp/` | When `CodPolicy.require_otp` is on |

### Orders, returns, reviews
| Method | Path | Notes |
|---|---|---|
| GET | `/orders/` · `/orders/{number}/` | Customer's own (object permission) |
| GET | `/orders/track/?number=&email=` | Guest tracking (rate-limited) |
| POST | `/orders/{number}/cancel/` | `{reason}`. Allowed before `shipped`. |
| GET | `/orders/{number}/invoice/` | Short-lived presigned PDF URL |
| GET/POST | `/returns/` · `/returns/{number}/` | `POST {order_number, lines:[{order_line_id, quantity, reason_code}], resolution, note, media_ids[]}` |
| GET | `/catalog/products/{slug}/reviews/` | Approved only. `?rating=&with_media=` |
| POST | `/reviews/` | Verified purchase only → `pending` |

### CMS (public)
| Method | Path | Notes |
|---|---|---|
| GET | `/cms/site-settings/` | Brand config, announcement, social |
| GET | `/cms/pages/{slug}/` | Published version: `{blocks:[{type, id, config}]}`. Configs are typed per block (discriminated union in OpenAPI). |
| POST | `/cms/newsletter/` | Double opt-in |

### Admin API (`/api/v1/admin/…`, staff + role permissions)
`dashboard/summary/`, `analytics/sales/?from=&to=&interval=day`, `products/` (CRUD, `bulk-import/` CSV/XLSX with dry-run validation report, `bulk-update/`), `products/{id}/media/` (presign → finalise → reorder → set colour/role), `variants/`, `categories/`, `collections/`, `attributes/{type}/`, `size-charts/`, `inventory/levels/`, `inventory/adjustments/`, `inventory/movements/`, `inventory/low-stock/`, `orders/` (+ `/{id}/transition/`, `/{id}/refund/`, `/{id}/shipments/`), `payments/`, `shipments/`, `customers/`, `returns/` (+ `/approve`, `/receive`, `/inspect`, `/refund`), `promotions/`, `coupons/`, `reviews/` (+ moderate), `cms/pages/` (+ versions, blocks, publish, schedule), `cms/media/`, `cms/site-settings/`, `staff/` & `roles/`, `audit-log/`.

### Internal
- `POST /frontend/api/revalidate` (Next.js route handler, shared secret) is called from Django `on_commit` when products, collections or CMS pages publish.
